This uses the existing shared screen lifecycle; no producer version contract or platform-specific behavior changes. Palette invalidation and full renderer-reset cleanup remain intact. Failed uploads leave dynamic entries invalid and return null, permitting retry at the same revision instead of accepting stale pixels.
- **Tradeoff:** pushing any screen invalidates all dynamic image entries, including images of an underlying screen. Only requested images upload again; ordinary repeated frames remain cached. Game-art/font caches are not invalidated by screen pushes. There is no image hashing, per-frame buffer comparison, new key namespace or ownership change.
